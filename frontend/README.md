# Сайт проекта

Статический сайт без сборки и зависимостей.

- `index.html` — лендинг: как устроен эпизод, четыре типа ошибок на примерах из настоящего эпизода, калькулятор награды, результаты стратегий на 20 открытых эпизодах, сами эпизоды и как подключить своего агента.
- `play.html` — песочница: настоящая среда через HTTP API. Можно делать шаги вручную или запустить автопилот (агент в браузере, `agent.js`): «Простая сверка» ищет только дубли, «Внимательный аудитор» применяет политику ко всем четырём типам ошибок. Оба видят только то, что видит любой агент.
- `explorer.html` — обозреватель открытых записей эпизода, по 50 строк на страницу; для демо-эпизода (dev, seed 2013) есть разбор, ответы к нему опубликованы в `docs/DEMO.md`.

## Запуск

Сайт вместе с API (нужно для песочницы):

```bash
make site                     # http://127.0.0.1:8000/, режим open: видна итоговая награда
make serve                    # то же в режиме closed: публичная награда всегда 0, как на закрытой проверке
PYTHONPATH=src:. python -m space_team_genesis.cli serve --mode open --port 8000   # без make
```

Лендинг и обозреватель работают и без сервера: двойной клик по `index.html` (данные подключены обычными `<script>`). Без сети подставятся системные шрифты.

Ссылки для показа: `play.html?auto=careful` сам создаёт эпизод и запускает внимательного аудитора; `play.html?profile=train&size=large&auto=simple` — простую сверку на крупной компании. `?theme=light|dark` принудительно включает тему.

## Условия в песочнице

Официальные: 100 шагов, 60 секунд с момента создания эпизода, контрактные действия и ошибки. Seed и режим оценки выбирает сервер. Лимит времени для человека не ослаблен, поэтому для ручной игры есть подсказки: клик по ID в ответе среды добавляет его в черновик вывода.

## Обновить данные

После изменения эпизодов, генератора, оценщика или политик:

```bash
python frontend/build_data.py
```

Скрипт берёт только `episodes/*/public`. Исключения: разбор демо-эпизода (ответы уже опубликованы в `docs/DEMO.md`) и таблицы стратегий, которые считаются настоящим оценщиком. Политики запускаются через публичный `reset/step`; оценщик для скорости работает в том же процессе, числа совпадают с `make report`.

Проверки сайта: `tests/test_web.py` (отдача файлов и защита путей) и `tests/test_browser_agent.py` (браузерный агент против оценщика на 20 эпизодах; пропускается без Node.js).
