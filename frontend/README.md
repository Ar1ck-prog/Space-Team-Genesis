# Сайт проекта

Статический сайт без сборки и зависимостей: лендинг и обозреватель открытых эпизодов.

- `index.html` — лендинг: как устроен эпизод, четыре типа ошибок на примерах из настоящего эпизода, калькулятор награды, стратегии, посчитанные настоящим оценщиком, и 20 открытых эпизодов.
- `explorer.html` — обозреватель: книга, счета, платежи и курсы эпизода так, как их видит агент, по 50 строк на страницу. Для демо-эпизода (dev, seed 2013) есть разбор ошибок, ответы к нему уже опубликованы в `docs/DEMO.md`.

## Открыть

Двойной клик по `index.html`: данные подключены обычными `<script>`, поэтому сайт работает прямо с диска, без сервера и без сети (без сети подставятся системные шрифты). Или так:

```bash
python -m http.server -d frontend 8000   # http://localhost:8000
```

`?theme=light` или `?theme=dark` в адресе принудительно включает тему, например для проектора.

## Обновить данные

После изменения эпизодов или генератора:

```bash
python frontend/build_data.py
```

Скрипт берёт только `episodes/*/public`. Единственное исключение — разбор демо-эпизода: его ответы и таблица стратегий пересчитываются из публичного seed настоящим оценщиком.

## Чего здесь нет

Живой песочницы поверх HTTP API: сейчас нет запускаемого сервера с фабрикой эпизодов (это зона бэкенда). Когда он появится, обозреватель можно переключить с файлов на `POST /api/v1/episodes` и `steps`.
