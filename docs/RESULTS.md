# Результаты базовых политик

Проверка интегрированной среды на 10 train и 10 dev эпизодах из [набора](DATASET.md). Команда:

```bash
PYTHONPATH=src:. python3 -m space_team_genesis.cli report --split all
```

Средние значения по 20 эпизодам, зафиксированные 20 ноября 2026. Время зависит от машины; остальные метрики воспроизводимы при той же версии кода.

| Политика | Эпизодов | Precision | Recall | F1 | Return | Шаги | Время, с |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| Случайная | 20 | 0.0000 | 0.0000 | 0.2000 | −0.6032 | 8.0 | 0.0194 |
| Простая сверка | 20 | 0.5000 | 0.1751 | 0.4415 | −0.1484 | 20.4 | 0.0350 |
| «Пометить всё» | 20 | 0.0000 | 0.0000 | 0.0000 | −1.0000 | 20.4 | 0.0361 |
| Oracle оценщика | 20 | 0.8000 | 0.8000 | 1.0000 | 1.0000 | 0.0 | 0.1283 |

Oracle не является публичной политикой: он исполняется только внутри процесса оценщика. Средние precision/recall равны 0.8, поскольку в четырёх чистых эпизодах оба значения по контракту равны 0, а F1 равен 1. Return учитывает штраф за шаги. Время oracle включает запуск изолированного процесса.

`make check` дополнительно запускает 94 теста, проверяет набор эпизодов и создаёт публичную траекторию одного dev-прогона в `outputs/trajectories.jsonl`; та же команда успешно прошла в контейнере с `--network none`.
