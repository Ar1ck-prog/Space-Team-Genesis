# Доверенная лаборатория версий агента

Это локальные инструменты разработчика для Issues #16 и #17, не новый публичный API. Контракт reset/step, 100 шагов, 60 секунд, matcher и награда не меняются. Работа офлайн, без платных API и GPU. Поддерживаются только три скриптовые политики проекта. Поля model_id и prompt сохраняются как метаданные, но не подключают модель и не влияют на эти политики.

Из корня репозитория:

    PYTHONPATH=src:. python3 -m space_team_genesis.lab run --policy reconcile --split train --out outputs/lab/a
    PYTHONPATH=src:. python3 -m space_team_genesis.lab run --policy mark-all --split train --out outputs/lab/b
    PYTHONPATH=src:. python3 -m space_team_genesis.lab compare outputs/lab/a/run.json outputs/lab/b/run.json
    PYTHONPATH=src:. python3 -m space_team_genesis.lab save-failure outputs/lab/a/run.json outputs/lab/b/run.json clean_small --out outputs/lab/known-failures/clean-small.json
    PYTHONPATH=src:. python3 -m space_team_genesis.lab test-failure outputs/lab/known-failures/clean-small.json outputs/lab/b/run.json
    PYTHONPATH=src:. python3 -m space_team_genesis.lab test-collection outputs/lab/known-failures outputs/lab/b/run.json
    PYTHONPATH=src:. python3 -m space_team_genesis.lab scan outputs/lab/known-failures/clean-small.json outputs/lab/a/run.json outputs/lab/b/run.json outputs/lab/a/run.json
    PYTHONPATH=src:. python3 -m space_team_genesis.lab restore outputs/lab/a/run.json --out outputs/lab/restored-a

Команда run принимает --repeats 1..20, --prompt, --model-id, --settings с JSON-объектом для random (seed и exploration_steps). У reconcile и mark-all настройки должны быть пустыми. Каждый повтор random использует seed агента + номер повтора; задание и seed среды остаются теми же. Каталоги запуска должны быть пустыми. Восстановление использует сохранённый снимок кода политики и создаёт новый каталог: оно не меняет рабочую ветку и историю Git.

## Артефакты и граница доверия

run.json содержит версию формата, метаданные агента (commit HEAD только когда исходник точно совпадает с ним; иначе null, SHA-256 исходника, prompt, settings, model_id), хеши исходников среды, оценщика и общего runner, хеш набора заданий, seed/config и доверенные поэпизодные P/R/F1, TP/FP/FN, return, шаги, время и статус. agent_source.json содержит снимок auditgym/policies.py и его хеш. Оба файла доверенные, с правами 0600. Они находятся в игнорируемом Git каталоге outputs/ и не должны монтироваться агенту. Выполнение снимка запускает код с правами доверенного локального runner; не загружайте туда неизвестный код.

public/*.jsonl — только публичные траектории формата API-контракта, с действиями, наблюдениями и доступной агенту наградой. В closed режиме reward=0. Seed, truth, provenance, оценка и диагностические поля туда не записываются. Для произвольного недоверенного агента отдельной песочницы эта лаборатория не предоставляет; её текущая область — скриптовые политики репозитория.

Идентичность сравнения требует одинаковые хеши среды, оценщика, runner, набора, split, число повторов и одинаковые seed/config/episode_id каждой пары. При несовместимости команда останавливается с ошибкой. regressed в сравнении — наблюдаемое ухудшение F1 либо рост FP при равном F1 на конкретном повторе, не доказательство обобщения. Для стохастической политики используйте несколько повторов и смотрите разброс; один запуск не доказывает стабильную регрессию.

## Сохранённый провал и история

save-failure разрешён только для train. Он повторно проигрывает обе публичные траектории через свежий изолированный оценщик, проверяет метрики и записывает ожидаемые P/R/F1/TP/FP/FN эталонной версии в доверенный JSON. Тест считается пройденным, если F1 не ниже и FP не выше эталона. Dev/закрытые задания не превращаются в коллекцию известных провалов. Успех на известных примерах не означает улучшения на отложенных данных.

scan принимает доступные версии в порядке истории и повторно запускает сохранённый тест на каждой. Показывает все наблюдаемые переходы pass→fail и fail→pass, diff снимка кода/выбранной политики/промпта/настроек, а также отдельный список pass→fail. Он не предполагает монотонность и не делает бинарный поиск. При смешанных исходах повторов verdict=uncertain, и такой переход не объявляется подтверждённым. Недоступный или изменённый снимок, среда либо оценщик приводят к явной ошибке, а не к фиктивному результату.

Это диагностика известных train-примеров. Независимая оценка на dev/закрытом наборе остаётся отдельной, а официальный make check — обязательным.

## Диагностика расследований (Issue #18)

Команды ниже — доверенные локальные эксперименты; они не расширяют публичный reset/step и не входят в официальный score. Используйте только скриптовые политики проекта и известные train-примеры. Артефакты содержат seed/метрики и должны оставаться в `outputs/`, отдельно от агента и публичных trajectories.jsonl.

Формат доверенного `run.json` теперь версии 3: ранние артефакты #16–17 без отметок времени и счётчиков просмотра несовместимы. Для диагностики создайте новые прогоны и сохранённый провал; исходные файлы остаются нетронутыми.

    PYTHONPATH=src:. python3 -m space_team_genesis.diagnostics branch outputs/lab/a/run.json clean_small 3
    PYTHONPATH=src:. python3 -m space_team_genesis.diagnostics branch outputs/lab/a/run.json clean_small 3 --replacement '{"kind":"calculator","expression":"1+1"}' --out outputs/lab/branch.json
    PYTHONPATH=src:. python3 -m space_team_genesis.diagnostics minimize outputs/lab/known-failures/clean-small.json outputs/lab/b/run.json --out outputs/lab/minimized.json --max-attempts 12 --time-limit 60
    PYTHONPATH=src:. python3 -m space_team_genesis.diagnostics mutations
    PYTHONPATH=src:. python3 -m space_team_genesis.lab run --policy reconcile --split train --out outputs/lab/reconcile-budget-20 --action-budget 20 --repeats 3

`branch` создаёт свежий изолированный эпизод и до выбранного действия проверяет совпадение действий политики и публичных переходов сохранённого запуска. Случайная политика восстанавливается детерминированным replay её состояния RNG и истории наблюдений. При несовпадении либо отсутствии доверенных временных отметок команда отказывает; неподдерживаемые внешние адаптеры не считаются восстановленными. Остаток 100 шагов следует replay, остаток 60 секунд — сохранённой отметке выбранного действия; после развилки идёт реальное время. Тайм-аут до следующего принятого шага без записи в траектории нельзя точно ветвить. CLI печатает краткое сравнение и сохраняет полные траектории только с `--out`. Оригинальный прогон не меняется.

`minimize` меняет внутренний план генератора, а не скрывает документы в интерфейсе. Каждый кандидат заново генерируется, проверяется `verify_episode` и запускается тем же агентом в новом изолированном оценщике. Сохраняются типы ошибок и нижние ограничения профиля; фиксируются размеры до/после, попытки, время и принятые шаги. Лимит времени мягкий: текущая проверка кандидата завершается перед остановкой; лимит попыток строгий. Абсолютная минимальность не обещается. Файл результата доверенный: он содержит seed и внутренний план.

`mutations` копирует matcher, оценщик, награду и тестовые векторы во временный каталог, по одной меняет проверку валюты, суммы, доказательств, взаимно однозначного сопоставления, штраф за шаг или скрытие закрытой награды и запускает реальные тесты. Отчёт показывает обнаруженные и выжившие мутации; эквивалентный контроль должен выжить. Официальные matcher и формула награды не переписываются, `make check` не запускает мутанты.

`--action-budget` ограничивает только политику экспериментальным ранним submit; окружение по-прежнему имеет контрактные 100 шагов и до 60 секунд. Такие запуски помечены `mode=experimental`, не сравниваются с официальными и не попадают в коллекцию известных провалов. Обычный `run` без флага — официальный режим. В `compare` есть поэпизодные значения и средние P/R/F1, TP/FP/FN, return, шагов, времени, `viewed_items` и `viewed_bytes`. Последние два считают все фактически возвращённые записи/документы, включая повторные чтения; байты — длина канонического UTF-8 JSON самих объектов, без обёртки ответа. Денежная стоимость не оценивается.
